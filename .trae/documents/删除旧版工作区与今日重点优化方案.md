# 删除旧版工作区 · 今日重点优化 · 清单参数列去前缀

## Summary

三件事，一次性收口：

1. **表格去前缀**：材料表 / 预算清单 / 概算清单的「通用参数」「详细参数」列，去掉单元格里的小字徽标，直接显示设备中心调用回来的内容。

### W2 · 今日重点智能推荐（[TodayPage.tsx](e:/02%20AI%20outpt/Trae%20work/RD%20Workstation%202.0/rd-workstation/src/features/today/TodayPage.tsx)）

1. 候选：`activeProjects`（status=designing/reviewing，已归档被 list 过滤）。
2. 排序打分（依次比较，权重高的在前）：
   1. **今日有截止任务**：openTasks 中 `project_id === p.id && due_at 日期 === 今天` 的任务数，从多到少；
   2. **AI 告警**：`DesignService.check(ps.id)` 遍历该系统，danger 权重 10 / warn 权重 1 求和，从多到少；
   3. **项目进度**：子系统平均 progress，从低到高（最需推进优先）；
   4. **最近更新**：`updated_at` 新到旧。
3. 取排序首位项目；系统选择：该项目内按 `progress` 升序（最需推进的子系统优先），并列取首个，无子系统则按原逻辑显示"添加子系统"。
4. UI：
   - 卡片保持原样式与文案；
   - 卡片加一个 `Select`（候选 = 智能排序前 5 项目，含当前选中项），可手动切换查看当天重点（仅本日视图状态，不持久化）；
   - 按钮文案由「进入工作区」改为「进入推导」，跳转 `/projects-v2/${active.id}/derive`（替代已删除的工作区）。
5. 同步收口 TodayPage 其余导航：L223、L319 → `/projects-v2/${id}`；L339 → `/projects-v2/${id}/derive`。
