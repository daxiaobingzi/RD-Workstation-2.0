## 2. 当前状态分析（已探索确认）

- 架构：React19 + Vite + Tailwind4 + Zustand(MemoryRepository) + React Router；服务层齐备（Project/Point/Bill/Budget/Design/Document/Revision Service）
- 表格体系（自研轻量路线，memory 硬约束）：
  - `sortable-table.tsx`：列宽拖/双击自适应/Ctrl+←→/列换序/行排序/布局记忆/显隐/展开行 —— 点表、材料/预算/概算主交互
  - `sys-grouped-table.tsx`：系统→五区（前端/终端/管材线缆/辅材/其他）分组面板 + 金额小计 —— 材料/预算/概算共用
  - `data-table.tsx`（TanStack）：点位勾选/排序
- 已确认决策：新建 projects-v2 并行；点表 UI 聚合不改模型；材料/预算/概算复用 bill/budget 链路；Word 导出用 HTML→.doc 不新增依赖；版本对比在现有 compareVersions 基础上富化
- 删除数据联动的代码位置：ProjectDetailPage 中 `DataLinkageStrip` 引用与其渲染区块（v2 根本不引入）

## 3. 实施计划（确认可视化方案后执行）

### 组织方式：新建 `features/projects-v2` 并行，旧版原样保留

### 3.1 路由与导航
- `router.tsx`：新增 `/projects-v2`、`/projects-v2/:projectId`、`/projects-v2/:projectId/:tab` 路由；旧 `/projects*` 不动
- `layout.tsx`：一级导航「项目」指向 `/projects-v2`（新中心为默认入口）

### 3.2 目录结构（新建）
```text
src/features/projects-v2/
├── ProjectsV2ListPage.tsx          # ① 主页面：项目列表 + 项目模版 + 备份/归档
├── ProjectV2Page.tsx               # 单项目壳：内部 tab 导航（11 个模块）+ 项目头（导出/导入备份、归档/恢复）
├── lib/
│   ├── export-notes-doc.ts         # ③ 设计说明汇总导出 Word（分级标题，HTML→.doc）
│   └── export-points-xlsx.ts       # ④ 项目级点位导出 Excel（分系统 Sheet + 汇总）
└── components/
    ├── OverviewV2.tsx              # ② 概览（去数据联动）
    ├── TemplateModal.tsx           # ① 项目模版：按类型选/生成/套用
    ├── DesignNotesV2.tsx           # ③ 设计说明（每系统一节 + Word 导出）
    ├── ProjectPointsV2.tsx         # ④ 项目级点表（树形分组 + 批量/单个/导入/导出）
    ├── PointBatchForm.tsx          # ④ 批量/单个新增点位弹窗（选系统）
    ├── PointImportDialogV2.tsx     # ④ 批量导入（复用 parsePointRows + importRows，加系统列）
    ├── DeriveResultsV2.tsx         # ⑤ 推导 + 推导规则
    ├── ProductListV2.tsx           # ⑥ 材料表（系统→五区）
    ├── BudgetListV2.tsx            # ⑦⑧ 预算清单 / 概算清单（富化档次/品牌）
    └── VersionsV2.tsx              # ⑩ 版本（富化对比）
```
> ⑨ 文档、⑪ 复盘：直接复用旧组件 `DocumentsTab` / `ReviewTab`（import 引用，不复制代码）

### 3.3 服务层小扩展（不影响旧版）
- `point.service.ts` 新增 `allByProject(projectId)`：项目级点位（含系统名/设备/建筑/弱电间名）
- `misc.service.ts` `DocumentService` 新增 `listByPsId(psId)`：设计说明按子系统归类
- **业态自定义**：项目「类型」列统一改为「业态」；借助现有 `dictionaries` 表 `group_code='project_type'` 开环字典承载（seed 预置 政府·公共安全/办公·智能楼宇/医疗/教育/酒店）；新建/编辑项目下拉可自由输入新增业态（写入字典），提供「业态管理」入口；**项目模版按业态配置与套用**（业态切换 → 模版列表联动；套用 → 新建项目自动带该业态 + 生成系统集与默认设计参数；「从当前项目生成模版」连同业态一起存档复用）。`Project.project_type` 字段语义接力为业态，无需改表。
- **设备中心富文本联动（材料表/预算清单/概算清单）**：
  - 「通用参数」= 设备名称 → 设备中心 `Product.specification` 富文本（表格内摘要 + 点击/悬停展开预览，设备中心同源联动）
  - 「详细参数」= 该行选型档次 → 品牌+型号 → `ProductModel.detail_html` 富文本（换档即改选品牌型号并刷新本列）
  - 复用 BillService.items 已有富化链路（spec/detail 摘要），补充富文本弹窗预览组件

### 3.4 各模块要点
**① 主页面**：照搬列表/看板/归档/搜索 + 新增「项目模版」弹窗（按项目类型内置模板集 → 套用自动生成系统；「从当前项目生成模板」写入 T.system_templates）；导出/导入备份、归档、级联删除照搬。**② 概览**：指标卡/摘要/子系统进度/近期任务/日程/文档，去掉 DataLinkageStrip。**③ 设计说明**：每系统一节（依据/点位概况/推导结果/设计参数 + 已有 design_note 文档编辑），导出全部为 Word。**④ 点表**：`allByProject` 按系统树形分组，列=建筑/弱电间/设备名称/数量+操作，SortableTable 全套交互 + 全选批量删；批量/单个新增选系统；导入加系统列；导出 xlsx 分系统。**⑤ 推导**：一键遍历系统 `DesignService.derive`，读视图展示公式/规则快照。**⑥ 材料表**：最新清单版本（无则生成），SysGroupedTable 五区+小计。**⑦⑧ 预算/概算**：`BudgetService.items` 富化档次/品牌/型号/详细参数；智能选型工具条（整项目/单系统三档，复用 applyGrade）；系统头合计金额；概算只读列序不同。**⑩ 版本**：点位时间线保留 + 清单对比富化（统计卡/按系统分组/筛选新增·移除·量变·价变/金额增量）。
